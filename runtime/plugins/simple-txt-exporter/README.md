# 轻量 TXT 群聊导出

这是一个比 QCE 更小的 NapCat 插件，只做三件事：

1. 复用 NapCat Framework 启动 QQ 和登录。
2. 列出当前 QQ 账号加入的群聊。
3. 选择一个或多个群聊后，把历史记录导出成纯文本 TXT。
4. 也可以导出 Excel `.xlsx`。单群列为“时间 / QQ号 / 名字 / 内容”；多群合并时会在最前面增加“群号”列。

## 使用

1. 确认 `config/plugins.json` 中启用了 `simple-txt-exporter`。
2. 退出正在运行的 QQ。
3. 在项目根目录运行 `napiLoader.bat`。
4. QQ 登录完成后访问 <http://localhost:40777/>。

## TXT 格式

默认每条消息导出为：

```txt
群名片/昵称(123456) 2026/07/14 20:15:03
消息内容
```

系统消息不会保留。多群合并导出会按照消息时间排序。Excel 单群导出会使用四列：时间、QQ号、名字、内容；多群导出会使用五列：群号、时间、QQ号、名字、内容。图片、语音、视频、文件等非纯文本内容会写成 `[图片:文件名]`、`[语音]`、`[文件:文件名]` 这样的占位文本。这个轻量版不会下载媒体资源。
